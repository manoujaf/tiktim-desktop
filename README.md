# TikTim for Desktop

Your smart personal assistant: tasks, goals, events and notes, on Linux and Windows.
It syncs with the TikTim Android app and [app.tiktim.com](https://app.tiktim.com), in English and Persian.

![TikTim: Today](screenshots/today.png)

## Download

Get the latest version from **[Releases](https://github.com/manoujaf/tiktim-desktop/releases/latest)**:

| System                    | File                         |
| ------------------------- | ---------------------------- |
| Windows 10 / 11           | `TikTim_x.y.z_x64-setup.exe` |
| Ubuntu / Debian / Mint    | `TikTim_x.y.z_amd64.deb`     |
| Fedora / openSUSE / RHEL  | `TikTim-x.y.z-1.x86_64.rpm`  |

Once installed, TikTim updates itself.

### Install on Linux

```bash
sudo apt install ./TikTim_*_amd64.deb      # Ubuntu / Debian
sudo dnf install ./TikTim-*.x86_64.rpm     # Fedora
```

## Features

- **Today**: the day's events and tasks in one place, with a calendar always at hand
- **Tasks**: dates, times, repetition, priority, steps and descriptions
- **Goals**: link tasks to a goal and watch its progress
- **Events**: begin and end times, repetition and reminders
- **Notes**: organized in categories
- **Sync**: one account across desktop, web and Android
- **Persian and English**, Jalali or Gregorian calendar, light and dark theme
